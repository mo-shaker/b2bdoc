## ما هذه

الفصول المرجعية تشرح شاشةً واحدة في المرة. وهذه السيناريوهات تأخذ **حالةً تشغيلية واحدة** من طرف إلى طرف، عبر كل دور وكل شاشة تمسّها.

وهي مكتوبةٌ لتُتَّبع لا لتُقرأ فحسب. فكلٌّ منها يسمّي الأدوار والسجلات والترتيب.

## ترتيب قراءة

| إن كنت | فاقرأ |
| --- | --- |
| **جديداً على SCOP** | تسليم كامل قياسي، ثم [دليل البدء السريع](../../quick-start/overview) |
| **تنفّذ اختبار قبول** | التسعة كلها، بالترتيب أعلاه |
| **تدرّب فريق مستودع** | تسليم كامل قياسي، تسليم جزئي، تأخّر التحميل |
| **تدرّب سائقين** | تسليم كامل قياسي، تسليم فاشل |
| **تدرّب مخطِّطين** | ملكية غير محلولة، لا مركبة ممكنة، تعديل الخطة |
| **تهيّئ نشراً** | عقدة تخطيط مفقودة، ملكية غير محلولة |

## سجلات العرض التوضيحي

تستخدم السيناريوهات قصةً واحدة متصلة، فيتعرّف القارئ المتابع لها بالترتيب على السجلات.

| المُعرِّف | دوره في القصة |
| --- | --- |
| **SCOP Manual Demo Customer** | العميل التجاري الأمّ |
| **SCOP Manual Branch A** | عقدة تخطيط، تسليمات عادية |
| **SCOP Manual Branch B** | فرعٌ ثانٍ — يُثبت أن الفرع المختلف زيارةٌ مختلفة |
| **SCOP Manual Branch C** | **بلا** عقدة تخطيط، عن قصد |
| **SCOP Manual Vehicle** | سعةٌ صغيرة، فيمكن بيان عدم الإمكان بصدق |
| **SCOP Manual Driver** | سائقٌ له موظف ورابط مستخدم |
| **SCOP Manual Consignment Supplier** | شريكٌ موسوم مالك أمانة |

:::note[مُعرِّفاتك ستختلف]

الأرقام المرجعية في هذه الصفحات — `DMD-2026-000010` وما إليها — أمثلة. وأرقامك ستكون مختلفة. و**الأشكال** هي المهمة.

:::

## قبل أن تبدأ أياً منها

| المتطلب | افحص |
| --- | --- |
| نطاق التجربة **Applied**، بأنواع العمليات الصحيحة | `Technical → Pilot Scope` |
| عُقَد التخطيط موجودة ومكتملة | `Master Data → Locations` |
| مركبة واحدة على الأقل لها ملف سعة | حقول SCOP على المركبة |
| موظف سائق واحد على الأقل مربوط بمستخدم | Odoo Employees |
| **شخصان** يستطيعان اعتماد الخطط | `Governance → Approval Authorities` |
| المخطِّطون يحملون Fleet → Administrator و Employees → Officer و Inventory → User | سجل المستخدم |

:::danger[المتطلب الذي يوقف المختبِر المنفرد]

`BR-PLN-001` يرفض اعتماد مؤلف الخطة نفسه، ولو كان مسؤول نظام.

**شخصٌ واحد لا يستطيع إكمال دورة SCOP.** رتّب معتمِداً ثانياً قبل أن تبدأ.

:::
