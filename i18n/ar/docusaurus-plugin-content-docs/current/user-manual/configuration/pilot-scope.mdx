**الدور**
مسؤول النظام

**انتقل إلى**
`SCOP → Technical → Pilot Scope`

## الخلاصة في سطر

:::warning[لا تتفاعل SCOP إلا مع العمليات المضبوطة داخل النطاق]

فإن لم يُشغَّل نوع عملية Odoo هنا، لم تفعل SCOP شيئاً حين يُنشأ تحويل من ذلك النوع. لا طلب، ولا حدث، ولا شيء.

وهذا أول ما يُفحَص حين يُقال *«SCOP لا تفعل شيئاً»*.

:::

## لماذا وُجد

المنصة التي تتفاعل مع كل حركة مستودع في الشركة كانت ستملأ سجل طلباتها بحركات لا ينوي أحد تخطيطها — من نقل داخلي وتسويات وإتلاف.

ونطاق التجربة يجعل التفاعل **اختياراً مقصوداً**، نوع عملية في كل مرة.

## أنواع العمليات

قائمة أنواع عمليات Odoo — Delivery Orders وReceipts وInternal Transfers وأي أنواع مخصَّصة — التي ينبغي أن تُولّد طلباً في SCOP.

| رمز نوع العملية | يُنتج نوع طلب |
| --- | --- |
| Outgoing | **Delivery** |
| Incoming | **Inbound** |
| Internal | **Transfer** |

والتحويل الذي ترتبط حركاته بحركة سابقة يُنتج **Return** مهما كان نوعه.

:::note[إضافة نوع عملية ليست بأثر رجعي]

تشغيل نوعٍ يؤثّر في التحويلات المُنشأة **بعد** التغيير. أما التحويلات القائمة من ذلك النوع فلا تكتسب طلبات فجأةً.

:::

## الإطلاق وغياب الملء الرجعي

لحظة **Go-Live** هي الحدّ الفاصل. والتحويلات المُنشأة قبلها لا تُنتج شيئاً.

:::danger[لا يوجد ملء رجعي للطلبات، عن قصد]

توليد طلبات لتحويلات وقعت قبل وجود SCOP كان سيُنتج تاريخ تخطيط لم يخطّطه أحد — سجلَّ قرارات لم تُتَّخذ قط، معروضاً بوصفه دليلاً.

والقاعدة مفروضة داخل التوليد نفسه، لا متروكةً لألّا يعيد أحد تشغيله — لأن إعادة تشغيله على التاريخ هي بالضبط ما يفعله أحدهم وهو يستقصي شيئاً آخر.

:::

والنتيجة العملية: قياسات التجربة تبدأ عند الإطلاق. فتوقّع أن تكون [OTIF](../reporting/otif.mdx) و[تغطية الخطة](../reporting/plan-coverage.mdx) بلا معنى في الدورة الأولى وصادقتين من الثانية.

## الحالات الثلاث

```text
Draft  →  Applied  →  Closed
```

| الحالة | المعنى | الأزرار |
| --- | --- | --- |
| **Draft** | قيد الضبط. **و SCOP لا تتفاعل بعد** | **Apply** |
| **Applied** | حيّ. وتتفاعل SCOP مع العمليات المضبوطة | **Close Pilot** |
| **Closed** | انتهت التجربة | — |

:::warning[سجل النطاق في Draft لا يفعل شيئاً]

ضبط أنواع العمليات لا يكفي. فـ**Apply** هو ما يُشغِّل SCOP.

والتجربة التي «أُعدَّت ولم يحدث شيء» غالباً ما تكون سجل نطاق ما زال قابعاً في Draft.

:::

## تطبيقه

| # | الخطوة |
| --- | --- |
| 1 | اضبط المستودع |
| 2 | أضِف أنواع العمليات التي ينبغي أن تُولّد طلباً |
| 3 | اضبط لحظة الإطلاق |
| 4 | اضغط **Apply** |
| 5 | أنشئ تحويلاً تجريبياً من نوع داخل النطاق |
| 6 | أكّد ظهور طلب |

## إغلاق التجربة

**Close Pilot** يُنهيها. استخدمه حين تنتهي التجربة ويحلّ محلها انتشارٌ أوسع، أو حين تُوقَف التجربة.

والإغلاق لا يحذف شيئاً. فالسجلات المُنشأة خلال التجربة تبقى.

## الإصدارات

`SCOP → Technical → Releases` *(مسؤول النظام)*

سجلٌّ بما نُشِر، ومتى، وكيف يمكن التراجع عنه.

| الحقل | المعنى |
| --- | --- |
| **Name** | مرجع الإصدار |
| **Released On** / **Released By** | متى وبمن |
| **Modules** | ما نُشِر |
| **Summary** | ما تغيّر. **مطلوب** |
| **Recovery Tier** | كيف سيتم التراجع |
| **Reverse Script** | التراجع، حيث يوجد |
| **Rehearsed On** | متى جُرِّب التراجع آخر مرة |

| Recovery Tier | المعنى |
| --- | --- |
| **Tier 1** | تعطيل خاصية |
| **Tier 2** | خفض إصدار وحدة |
| **Tier 3** | إزالة وحدة |
| **Tier 4** | استعادة قاعدة البيانات |

:::note[Rehearsed On هو الحقل الذي يهم]

خطة تعافٍ لم يجرّبها أحد أمنيةٌ لا خطة. والحقل موجود ليجعل ذلك ظاهراً.

:::

## التحقق

| تحقّق | أين | توقّع |
| --- | --- | --- |
| أن سجل النطاق **Applied** | `Technical → Pilot Scope` | الحالة Applied |
| أن أنواع العمليات الصحيحة في النطاق | حقل **Operation Types** | قائمتك |
| أن الإطلاق مضبوط صحيحاً | **Go-Live** | اللحظة المقصودة |
| أن تحويلاً تجريبياً يُنتج طلباً | `Operations → Demands` | الطلب |
| أن التوليد سُجِّل | `Technical → Domain Events` | `DemandGenerated` |

## إذا لم ينجح

| العَرَض | السبب | العلاج |
| --- | --- | --- |
| لا طلبات إطلاقاً ولا أحداث إطلاقاً | سجل النطاق في **Draft** | اضغط **Apply** |
| نفسه | نوع العملية خارج النطاق | أضِفه، وطبّق ثانيةً |
| نفسه، للتحويلات الأقدم فقط | سابقة للإطلاق | متوقَّع. فلا ملء رجعي |
| طلبات لبعض الوجهات فقط | عقدة تخطيط مفقودة | [تشخيص العقدة المفقودة](./missing-node-diagnostics.mdx) |
| تظهر طلبات لكن لعمليات خاطئة | أنواع عمليات كثيرة جداً في النطاق | أزِل ما لا تنوي تخطيطه |
| توقّفت الطلبات عن الظهور | أُغلقت التجربة | افحص الحالة |
