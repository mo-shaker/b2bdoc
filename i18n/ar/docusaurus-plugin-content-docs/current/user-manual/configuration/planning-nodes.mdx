وسائر الفصول تحيل إلى هنا بدل إعادة الشرح.

**الأدوار**
مسؤول النظام يُنشئ ويصون. والمخطِّط يقرأ وقد يعدّل.

**انتقل إلى**
`SCOP → Master Data → Locations`

## ما عقدة التخطيط

**مكانٌ فعلي تستطيع SCOP رسم مسار إليه**: مستودع، أو فرع عميل، أو موقع مورّد.

وهي تحمل ما يحتاجه رسم المسارات فعلاً — إحداثيات، ومنطقةً زمنية، وساعات فتح، ومدة خدمة — ولا شيء من ذلك يوجد على جهة اتصال في Odoo ولا على موقع مخزون.

:::warning[عقدة التخطيط ليست عنواناً في Odoo]

بل هي **سجل مستقل مرتبط بـ**جهات الاتصال والمستودعات ومواقع المخزون، وليست مشتقةً من أيٍّ منها.

وإنشاء عميل في Odoo **لا** يُنشئ عقدة تخطيط. فلا بد أن يفعلها أحد، وإلى أن يفعل، لا تُنتج التسليمات إلى ذلك العميل أي طلب.

:::

## لماذا تُوقِف العقدة المفقودة كل شيء

يحلّ توليدُ الطلبات **طرفَي** التحويل كليهما إلى عُقَد تخطيط. فإن تعذّر حلّ أحدهما، **لا يُنشأ طلب**.

وذلك مقصود: فالطلب الذي لا يستطيع أحد رسم مساره ولا قياسه أسوأ من لا طلب. لكنه ليس صامتاً — إذ يُسجَّل حدث `DemandGenerationSkipped` يسمّي التحويل والموقع غير المربوط والشريك وأي الطرفين أخفق.

→ [تشخيص العقدة المفقودة](./missing-node-diagnostics.mdx)

### الهوية

| الحقل | المعنى | مطلوب |
| --- | --- | --- |
| **Name** | ما تُسمّى | **نعم** |
| **Code** | مرجع قصير، مثل `QSD-WH` | مستحسن |
| **Location Type** | أي نوع من الأماكن | **نعم** |

| Location Type | استخدمه لـ |
| --- | --- |
| **Warehouse** | مكان تغادر منه البضائع |
| **Customer Branch** | مكان تُسلَّم إليه البضائع |
| **Supplier Location** | مكان تُجمَع منه البضائع |
| **Cross-Dock Facility** | نقطة تحويل |
| **Return Point** | حيث تُستقبَل المرتجعات |
| **Other** | أي شيء آخر |

### الروابط

| الحقل | يربط بـ | الغرض |
| --- | --- | --- |
| **Partner** | جهة اتصال في Odoo | كيف يُحَل تحويل عميل إلى هذه العقدة |
| **Warehouse** | مستودع في Odoo | كيف يُحَل تحويل مستودع إلى هذه العقدة |
| **Stock Location** | موقع مخزون في Odoo | المنشأ الفعلي الدقيق |

:::info[الروابط هي كيفية عمل الحلّ]

حين يُنشأ تحويل، تسأل SCOP مواقعَ مخزونه وشريكَه أي عقدة تقابلها. فإن لم يشر إليها شيء هنا، أخفق الحلّ.

وعقدة **فرع العميل** ترتبط عادةً بالشريك. وعقدة **المستودع** ترتبط عادةً بالمستودع وموقع مخزونه.

:::

### الجغرافيا

| الحقل | المعنى | مطلوب للتخطيط |
| --- | --- | --- |
| **Street** و**City** و**Country** | العنوان | لا |
| **Latitude** و**Longitude** | الإحداثيات، بسبع خانات عشرية | **نعم** |
| **Is Geocoded** | محسوب — هل توجد إحداثيات | — |
| **Geocode Source** | يدوي · مزوّد · منسوخ من الشريك · مُصطنَع | — |
| **Geocoded On** | متى | — |

:::warning[العقدة بلا إحداثيات تُنتج مسارات غريبة]

حيث لا تحمل مصفوفة السفر مسافةً لزوج من العقد، يعاملها المخطِّط على أنها **كبيرة جداً** لا صفراً — لأن المسافة المجهولة يجب ألّا تجعل عقدتين تبدوان متجاورتين فتتصدّران كل مسار.

والعَرَض الظاهر ليس خطأً. بل مسارٌ لا معنى له.

:::

### الزمن

| الحقل | المعنى | مطلوب |
| --- | --- | --- |
| **Timezone** | المنطقة الزمنية بمعيار IANA، مثل `Asia/Riyadh` | **نعم** |

:::danger[كل نافذة زمنية تُفسَّر بالمنطقة الزمنية للعقدة نفسها]

لا بمنطقة الخادم، ولا بمنطقة القارئ. فالعقدة ذات المنطقة الزمنية الخاطئة ستُزار في الساعة الخاطئة، وستقيس [OTIF](../reporting/otif.mdx) الالتزام بالوقت مقابل النافذة الخاطئة.

:::

### مدة الخدمة

كم تستغرق الزيارة، قبل السفر.

| الحقل | المعنى |
| --- | --- |
| **Service Duration Mode** | Fixed · Per line · Per unit |
| **Service Duration (min)** | الرقم الأساس |
| **Service Duration Variable (min)** | الإضافة لكل سطر أو لكل وحدة |

| النمط | المدة هي |
| --- | --- |
| **Fixed** | الرقم الأساس، مهما حملت الزيارة |
| **Per line** | الأساس زائد المتغيّر × عدد الأسطر |
| **Per unit** | الأساس زائد المتغيّر × عدد الوحدات |

:::info[هذا ما يجعل الزيارة المدموجة أقل كلفةً من زيارتين منفصلتين]

حين يتشارك متطلبان محطةً، تُسأل العقدة عن مدة **زيارة واحدة تحمل كليهما**. فيُحتسَب زمن التهيئة الثابت مرةً واحدة.

ولو جُمِع الرقمان المنفصلان لبدت الزيارة المدموجة أطول من الزيارتين اللتين حلّت محلهما.

→ [الزيارة الفعلية](../shipments/the-physical-visit.mdx)

:::

### الوصول

| الحقل | المعنى |
| --- | --- |
| **Dock Count** | كم مركبةً يمكن خدمتها في آن |
| **Requires Appointment** | هل يجب حجز موعد الوصول |
| **Plannable** | هل يجوز للتخطيط رسم مسار إلى هنا أصلاً |

## نوافذ الفتح

تبويب **Windows**. سطر لكل نطاق يوم-ووقت تكون العقدة فيه مفتوحة.

| الحقل | المعنى |
| --- | --- |
| **Day of Week** | أي يوم |
| **Time From** / **Time To** | ساعات محلية، بالمنطقة الزمنية للعقدة نفسها |
| **Mandatory** | هل يجب احترام النافذة أم هي تفضيل |
| **Valid From** / **Valid To** | صلاحية موسمية اختيارية |
| **Spans Midnight** | محسوب، حيث يعبر النطاق حدّ اليوم |

:::warning[العقدة بلا نوافذ لا تكون مفتوحةً أبداً]

لا يستطيع التخطيط جدولة زيارة في نافذة غير موجودة. فيعود الطلب غير مخطَّط بسبب *Customer location unavailable* أو *Missing required data*.

وكل عقدة تحتاج نافذةً واحدة على الأقل.

:::

### النوافذ مقابل التعهدات

[تعهُّد الخدمة](./service-commitments.mdx) **يعلو** على ساعات فتح العقدة نفسها. فالوعد أخصّ من وقت الفتح.

والأسبقية نفسها تقرّر هل يتشارك متطلبان زيارةً فعلية — انظر [الزيارة الفعلية](../shipments/the-physical-visit.mdx).

## قيود الوصول

تبويب **Constraints**. ما يجب أن تستوفيه المركبة لخدمة هذه العقدة.

| نوع القيد | القيمة |
| --- | --- |
| **Maximum vehicle length (m)** | حدّ |
| **Maximum vehicle height (m)** | حدّ |
| **Maximum vehicle weight (kg)** | حدّ |
| **Requires a tail lift** | قدرة |
| **Requires a forklift on site** | قدرة |
| **One-way access** | خاصية مسار |

| الحقل | المعنى |
| --- | --- |
| **Hard** | هل يحجب القيد أم ينبّه فقط |
| **Rule** | قاعدة العمل التي تفرضه، حيث تنطبق واحدة |
| **Note** | نص حر |

والطلب الذي لا تستطيع مركبةٌ متاحة استيفاءه يعود غير مخطَّط بسبب *Route restriction*.

## استيراد العقد بالجملة

`SCOP → Master Data → Import Locations` *(مسؤول النظام)*

للتجربة بفروع عملاء كثيرة، هذا أسرع من إنشاء كلٍّ يدوياً. اضغط **Run** للتنفيذ، واقرأ النتيجة قبل الإغلاق.

## مصفوفة السفر

`SCOP → Technical → Travel Matrix` *(مسؤول النظام)*

مسافات ومُدد مخزَّنة بين أزواج العقد. ويقرؤها التخطيط لتقدير السفر.

:::note[العقد غير المُحدَّثة إحداثياً تُتخطَّى ولا تُملأ بقيم افتراضية]

فالعقدة بلا إحداثيات لا تنال مدخلات في المصفوفة، بدل أن تنال مدخلات بصفر. وهو المنطق نفسه الذي يطبّقه المخطِّط على المسافات المجهولة — فالافتراض بصفر كان سيجعل عقدتين تبدوان متجاورتين.

:::

## إنشاء عقدة — قائمة التحقق

| # | اضبط | وإلا |
| --- | --- | --- |
| 1 | **Name** و**Location Type** | لا يمكن حفظها |
| 2 | رابط **الشريك** أو **المستودع** أو **موقع المخزون** | لن تُحَل التحويلات إليها |
| 3 | **Latitude** و**Longitude** | لا معنى للمسارات |
| 4 | **Timezone** | تُفسَّر النوافذ خطأً |
| 5 | **نافذة فتح** واحدة على الأقل | لا يمكن جدولة شيء هنا أبداً |
| 6 | **مدة الخدمة** | توقيت المسار خاطئ |
| 7 | أي **قيود وصول** | سترسَل مركبات لا تستطيع خدمتها |

## التحقق

| تحقّق | أين | توقّع |
| --- | --- | --- |
| وجود العقدة | `Master Data → Locations` | سطر واحد |
| أنها محدَّدة إحداثياً | **Is Geocoded** | صحيح |
| أن لها منطقةً زمنية | **Timezone** | منطقة IANA |
| أن لها نوافذ | تبويب **Windows** | واحدة على الأقل |
| أن التحويلات تُحَل إليها | أنشئ تحويلاً تجريبياً | يظهر طلب |
| ألّا تبقى أحداث تخطٍّ | `Technical → Domain Events` | لا `DemandGenerationSkipped` جديد |

## إذا لم ينجح

| العَرَض | السبب | العلاج |
| --- | --- | --- |
| لا طلب للتسليمات إلى هذا العميل | لا عقدة، أو الشريك غير مربوط | أنشئ العقدة أو اربطها، وأعِد حفظ التحويل |
| `DemandGenerationSkipped` يسمّي موقع مخزون | ذلك الموقع لا يُحَل إلى عقدة | اربطه |
| تظهر طلبات لكنها تعود *Missing required data* | الإحداثيات أو المنطقة الزمنية أو النوافذ ناقصة | أكمِل العقدة |
| تعود الطلبات *Customer location unavailable* | لا نافذة تغطي التاريخ المخطَّط | أضِف نافذة |
| المسارات بلا معنى | العقدة غير محدَّدة إحداثياً | اضبط الإحداثيات |
| التسليمات تصل في الساعة الخاطئة | المنطقة الزمنية خاطئة | صحّحها |
| مركبة لا تستطيع خدمة العقدة | قيد وصول يستبعدها | افحص تبويب **Constraints** |
