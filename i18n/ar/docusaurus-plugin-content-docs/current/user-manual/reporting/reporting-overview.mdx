## أي تقرير يجيب عن أي سؤال

| السؤال | التقرير | من يقرؤه |
| --- | --- | --- |
| هل خطّطنا ما كان يمكن تخطيطه؟ | [تغطية الخطة](./plan-coverage.mdx) | المخطِّط والإدارة |
| ما الذي عجزنا عن تخطيطه، ولماذا؟ | [الطلبات غير المخطَّطة](./unplanned-demand-report.mdx) | المخطِّط |
| كم كانت المركبات ممتلئة؟ | [استغلال المركبات](./vehicle-utilization.mdx) | المخطِّط والإدارة |
| هل سلّمنا في الوقت وبالكامل؟ | [OTIF](./otif.mdx) | الجميع |
| كم كانت الخطة قريبةً من الواقع؟ | [المخطَّط مقابل الفعلي للرحلة](./trip-planned-vs-actual.mdx) | العمليات |
| أي المشكلات تأخّرت؟ | [تقادم الاستثناءات](./exception-ageing.mdx) | مدير العمليات |
| كم مرةً نتجاوز التوصية؟ | [جودة القرار](./decision-quality.mdx) | المخطِّط والإدارة |
| ماذا حدث لهذه العملية؟ | [الخط الزمني للعملية](./operation-timeline.mdx) | الجميع |
| ما الذي أخفقت SCOP في تسجيله؟ | [تقارير جودة البيانات](./data-quality-reports.mdx) | مسؤول النظام |
| ما الذي تحرّك ولا يغطّيه طلب؟ | [تقارير جودة البيانات](./data-quality-reports.mdx) | مسؤول النظام |
| كم من الملكية غير محلولة؟ | [تقارير جودة البيانات](./data-quality-reports.mdx) | الجميع |
| ماذا يجري اليوم؟ | [لوحة المعلومات](./the-dashboard.mdx) | المخطِّط والإدارة |

## المجموعات الثلاث

| المجموعة | التقارير | الغرض |
| --- | --- | --- |
| **هل خطّطنا جيداً؟** | تغطية الخطة، الطلبات غير المخطَّطة، جودة القرار، استغلال المركبات | جودة التخطيط |
| **هل نفّذنا جيداً؟** | OTIF، المخطَّط مقابل الفعلي، تقادم الاستثناءات | الأداء التشغيلي |
| **هل البيانات سليمة؟** | الإسقاطات الفاشلة، الحركات اليتيمة، جودة بيانات الملكية | هل يمكن الوثوق بالمجموعتين الأخريين |

:::warning[اقرأ تقارير جودة البيانات قبل استخلاص نتائج من غيرها]

فإن كانت الحركات اليتيمة غير فارغة، كانت تغطية الخطة **مبالَغاً فيها** — إذ تقيس SCOP مقابل طلبٍ أقل مما هو موجود فعلاً.

وإن أظهرت جودة بيانات الملكية عدداً كبيراً غير محلول، كان التخطيط يرفض عملاً قد لا تدرك أنه يُرفض.

→ [تقارير جودة البيانات](./data-quality-reports.mdx)

:::

## أعراف تسري على كل تقرير

| العُرف | العاقبة |
| --- | --- |
| التقارير **للقراءة فقط** | لا يمكنك إصلاح بيانات من تقرير. افتح السجل الأصل |
| بعضها يفتح بـ**مُرشِّح افتراضي** | أزِله عمداً لا سهواً |
| **مقياس النسبة يُتوسَّط** لا يُجمَع | جمع التغطية عبر خمسة أيام بلا معنى |
| معظمها يوفّر عرض **Pivot** | وهناك تكمن القيمة — اسحب الأبعاد إلى الصفوف والأعمدة |
| البيانات تبدأ عند **الإطلاق** | فلا ملء رجعي للتاريخ |

### المُرشِّحات الافتراضية

| التقرير | يفتح بـ |
| --- | --- |
| OTIF | السجلات التي **تحمل تعهداً** |
| الطلبات غير المخطَّطة | مُجمَّعةً بـ**السبب** |
| استغلال المركبات | مُجمَّعاً بـ**المركبة** |
| المخطَّط مقابل الفعلي للرحلة | الرحلات **المكتملة والمكتملة جزئياً** فقط |
| جودة القرار | مُجمَّعةً بـ**هل عُدِّلت الخطة** |
| جودة بيانات الملكية | مُجمَّعةً بـ**الحلّ** |
| الإسقاطات الفاشلة | الأحداث **الفاشلة** فقط |
| الحركات اليتيمة | الحركات التي **لا يغطّيها سطر طلب** |
| الاستثناءات | الاستثناءات **المفتوحة** |

:::note[السجل الذي يبدو مفقوداً يكون مُرشَّحاً عادةً]

قبل أن تستنتج أن SCOP لم تسجّل شيئاً، أفرِغ شريط البحث تماماً. وهذا أشيع إنذار كاذب خلال اختبار القبول.

:::

## ترتيب قراءة أسبوعي

لقارئ من مدير العمليات أو الإدارة، بهذا الترتيب:

| # | اقرأ | لأن |
| --- | --- | --- |
| 1 | **جودة بيانات الملكية** و**الحركات اليتيمة** | لتُثبت هل يمكن الوثوق بالباقي |
| 2 | **تغطية الخطة** | هل خطّطنا ما استطعنا؟ |
| 3 | **الطلبات غير المخطَّطة** | وإن لم نفعل، فلماذا؟ |
| 4 | **OTIF** | هل وفّينا بوعودنا؟ |
| 5 | **تقادم الاستثناءات** | ما المتأخر؟ |
| 6 | **جودة القرار** | هل نثق بالتوصية؟ |
| 7 | **استغلال المركبات** | هل حجم الأسطول صحيح؟ |

## ما ليس في تقارير الإصدار الأول

| غير متاح | ملاحظة |
| --- | --- |
| إرسال التقارير بالبريد مجدولاً | اقرأ التقارير، أو احفظ مفضّلة |
| التنبيهات الآلية | لا يُبلِّغ أحداً إلا تصعيد الاستثناءات |
| لوحة Dashboard Ninja | بُنيت وتُركت عمداً غير قابلة للتركيب — فكل مقياس فيها موجود في التقارير القياسية |
| أداء المورّدين | لا يوجد ما يعادل OTIF للمورّدين |
| توفيق التكاليف مع دفتر الأستاذ | أرقام التكلفة تقديرات تخطيطية فقط |
| المقاييس التنبؤية | لا يُشحَن نموذج تنبؤ في الإصدار الأول |
