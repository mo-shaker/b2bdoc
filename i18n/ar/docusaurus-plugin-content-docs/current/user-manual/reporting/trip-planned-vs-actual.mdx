## الغرض

يجيب عن **كم كانت التقديرات جيدة**. فإن تباعد المخطَّط والفعلي باطّراد، كانت البيانات الأساس وراء التقديرات خاطئة — وكل خطة مبنية عليها خاطئة في الاتجاه نفسه.

## الجمهور

العمليات والتخطيط.

## انتقل إلى

`SCOP → Reporting → Trip Planned vs Actual`

## المُرشِّحات

يفتح مُرشَّحاً على الرحلات **Completed** و**Partially Completed**. فالرحلة الجارية بلا أرقام فعلية.

| البعد | الاستخدام |
| --- | --- |
| **Vehicle** | بُعد الصفوف الافتراضي |
| **Driver** | هل تتبع الفجوة شخصاً |
| **Planned Start** | عبر الزمن |
| **Status** | المكتملة مقابل المكتملة جزئياً |

## المقاييس

| المقياس | المعنى |
| --- | --- |
| **Planned Duration (min)** / **Actual Duration (min)** / **Duration Variance** | الزمن |
| **Planned Distance (km)** / **Actual Distance (km)** / **Distance Variance** | المسافة |
| **Planned Cost Estimate** / **Execution Cost Estimate** / **Cost Variance** | التكلفة |

و**التباين الموجب** يعني أن الفعلي تجاوز المخطَّط.

## كيف تقرؤه

ابحث عن **الاطّراد** لا عن التباينات المفردة. فرحلةٌ طويلة واحدة زحام. أما كل رحلة تزيد 30% فمشكلة بيانات.

| النمط | السبب المرجّح | العلاج |
| --- | --- | --- |
| المدة تزيد باطّراد | مدد الخدمة أو تقديرات السفر متفائلة أكثر مما ينبغي | [عُقَد التخطيط](../configuration/planning-nodes.mdx)، ومصفوفة السفر |
| المدة تنقص باطّراد | التقديرات متشائمة أكثر مما ينبغي. فأنت لا تستغل اليوم | نفسه |
| المسافة تزيد باطّراد | مسافات مصفوفة السفر قصيرة، أو السائقون يحيدون | مصفوفة السفر |
| التباين متركّز على مركبة واحدة | متوسط سرعتها خاطئ | [الأسطول والمركبات](../configuration/fleet-and-vehicles.mdx) |
| التباين متركّز على عقدة واحدة | مدة خدمتها خاطئة | العقدة |
| تباين تكلفة بلا تباين مدة ولا مسافة | معدلات التكلفة خاطئة | المركبة |

## مثال

```text
Vehicle              Planned min   Actual min   Variance
SCOP Manual Vehicle       240          312         +72
Van 2                     180          235         +55
Van 3                     300          388         +88
```

كل مركبة تزيد نحو 30%. وهذه ليست ثلاث مشكلات سائقين — بل مشكلة **تقدير** واحدة، على الأرجح مدد خدمة مضبوطة أدنى مما ينبغي على العقد.

وتصحيح البيانات الأساس يجعل كل خطة قادمة أكثر واقعية، ويحسّن [OTIF](./otif.mdx) عرضاً: فالخطة التي تتيح وقتاً كافياً تصل داخل نافذتها.

## أخطاء التفسير الشائعة

:::warning[تباين التكلفة ليس رقماً مالياً]

معدلات التكلفة **تقديرات تشغيلية لمقارنة الخطط**. ولا شيء يوفّقها مع دفتر الأستاذ، ويجب ألّا تُذكَر أبداً بوصفها تكلفة مبيعات.

→ [نطاق الإصدار الأول](../about/release-1-scope.mdx)

:::

| الخطأ | لماذا هو خطأ |
| --- | --- |
| قراءة تباين رحلة واحدة على أنه أداء | الرحلة الواحدة طقسٌ وزحامٌ وحظ |
| لوم السائقين على نمط يعمّ الأسطول | الفجوة المطّردة مشكلة تقدير |
| تجاهل التباين السالب | الوصول المبكر باطّراد يعني أن اليوم غير مستغَلّ |
| المقارنة قبل تغيير بيانات أساس وبعده | التقديرات المختلفة غير قابلة للمقارنة |
| استخدام أرقام التكلفة في تقارير مالية | هي تقديرات تخطيطية |

## مدة التحميل

تُقاس مدة التحميل الفعلية لكل شحنة على مهمة التحميل، وتسهم في المدة الفعلية للرحلة.

والرحلة التي تزيد مدتها باطّراد بينما السفر طبيعي غالباً ما تكون مشكلة **تحميل** لا مشكلة رسم مسار — فافحص مهام التحميل.

→ [عمليات التحميل](../execution/loading-operations.mdx)
