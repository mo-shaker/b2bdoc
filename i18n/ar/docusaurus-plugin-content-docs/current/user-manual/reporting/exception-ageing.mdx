## الغرض

يجيب عن **ما المتأخر، ومن يملكه**.

## الجمهور

مدير العمليات أساساً. والإدارة للنمط.

## انتقل إلى

`SCOP → Reporting → Exception Ageing`

## المُرشِّحات

لا مُرشِّح افتراضي. رشِّح على المتأخر، أو على فئة، حسب الحاجة.

| **Severity** | الحرج أولاً |
| **Owner** | طابور من |
| **Status** | أين في دورة الحياة |
| **Overdue** | تجاوز الموعد النهائي |

## المقاييس

| المقياس | المعنى |
| --- | --- |
| **Age (hours)** | منذ كشف الاستثناء |
| **Hours Past Deadline** | السالب يعني أنه ما زال في الوقت |
| **Escalation Count** | كم مرة صُعِّد |
| عدد الأسطر | كم استثناءً |

اقرأه بهذا الترتيب:

| # | انظر إلى | السؤال |
| --- | --- | --- |

## الاتفاقية تأتي من الفئة

كلٌّ من الفئات الاثنتي عشرة تحمل اتفاقيتها. والعمر يجب أن يُقرأ **مقابل الفئة**، لا مجرداً أبداً.

| الفئة | الاتفاقية |
| --- | --- |
| Vehicle breakdown | **ساعتان** |
| Critical rule failure، Unauthorized configuration | 4 س |
| Inventory shortage، No feasible plan، Picking delay | 4 س |
| Invalid shipment composition، Customer window change، Delivery rejection، Route restriction | 8 س |
| Supplier delay | 24 س |
| Invalid KPI result | 48 س |

فعطل مركبة عمره ست ساعات تجاوز ثلاثة أضعاف. وتأخر مورّد عمره ست ساعات أمامه ثماني عشرة ساعة.

→ [إدارة الاستثناءات](../exceptions/exception-management.mdx)

## مثال

```text
Category                  <4h   4-8h   8-24h   >24h   Overdue
Vehicle breakdown           1      0       0      0      1
Picking delay               3      2       0      0      2
Supplier delay              0      1       4      2      2
Invalid KPI result          0      0       1      3      0
```

| السطر | القراءة |
| --- | --- |
| **Vehicle breakdown**، دون 4 س، ومتأخر بالفعل | اتفاقيته ساعتان. **وهذا ما يُتصرَّف فيه الآن** |
| **Picking delay**، اثنان متأخران | مشكلة سعة مستودع |
| **Supplier delay**، ستة مفتوحة | ليست عاجلةً فرادى، لكنها نمط مشتريات |
| **Invalid KPI result**، لا متأخر | اتفاقيته 48 س. تجاهله الآن |

فالسطر الأحدث هو الأعجل. ولهذا لا يكون العمر وحده جواباً أبداً.

## أخطاء التفسير الشائعة

| الخطأ | لماذا هو خطأ |
| --- | --- |
| الفرز بالعمر والعمل على الأقدم أولاً | تأخر مورّد عمره 30 ساعة في الوقت؛ وعطل عمره 3 ساعات ليس كذلك |
| عدّ **Age Bucket** استعجالاً | الاستعجال هو العمر **مقابل اتفاقية الفئة** |
| تجاهل عدد التصعيد | الاستثناء المُصعَّد مرتين لا يُعمَل عليه |
| افتراض أن التقرير الفارغ خبر سار | قد يعني أن لا أحد يرفع استثناءات |

:::warning[طابور الاستثناءات الفارغ ليس خبراً ساراً تلقائياً]

الاستثناءات تُرفع **عمداً**. والطابور الفارغ دائماً في عملية مزدحمة يعني عادةً أن المشكلات تُعالَج بغير رسمية ولا تُسجَّل قط — ما يعني أنها لا تُحصى ولا تُصعَّد ولا تُصلَح من منبعها.

:::

:::info[الاستثناء في Detected يتقادم كذلك]

ساعة الاتفاقية تبدأ عند **Detected At** لا عند التصنيف — فالفئة مطلوبة لإنشاء الاستثناء أصلاً، والموعد يُحسَب منها فوراً.

فالاستثناء غير المُصنَّف **يظهر** هنا و**يُعرَض** متأخراً متى مضى موعده. وإنما لا أحد يقرّ به.

والاستثناء **بلا موعد إطلاقاً** يعني أن فئته بلا ساعات اتفاقية مضبوطة، وهذا شأن إعدادات لمسؤول النظام.

:::
