## الغرض

شاشة واحدة تجيب عن *ماذا يجري الآن*، لمخطِّط يبدأ يومه أو مدير يلقي نظرةً على العملية.

**الجمهور**
المخطِّط/المُرسِل والإدارة. وهي غير مرئية للأدوار الأخرى.

**انتقل إلى**
`SCOP → Dashboard` — أول مدخل تحت `SCOP`.

## ماذا تعرض

<Screenshot
  src="user-manual/71-dashboard.png"
  alt="لوحة معلومات SCOP تعرض ملخّصاً للعملية الجارية."
  caption="اللوحة نقطة بداية. ووراء كل رقم فيها تقرير."
/>

تلخّص اللوحة عملية اليوم من البيانات نفسها التي تقرؤها التقارير. وهي **نقطة بداية** لا أداة تحليل: فوراء كل رقم فيها تقريرٌ يمكن ترشيحه وتجميعه وتدويره.

| القراءة | تعمّق في |
| --- | --- |
| طلبٌ لم يُخطَّط بعد | [الطلبات غير المخطَّطة](./unplanned-demand-report.mdx) |
| خطط تنتظر الاعتماد | `Planning → Daily Plans` |
| رحلات جارية | `Operations → Trips` |
| استثناءات مفتوحة | [تقادم الاستثناءات](./exception-ageing.mdx) |
| أداء الخدمة | [OTIF](./otif.mdx) |
| التغطية | [تغطية الخطة](./plan-coverage.mdx) |

## متى تستخدمها ومتى لا

| استخدم اللوحة | استخدم تقريراً |
| --- | --- |
| لبدء يومك | للإجابة عن سؤال محدَّد |
| لفحص صحة سريع | لأي شيء يحتاج مُرشِّحاً أو مدى تواريخ |
| لتُري أحدهم العملية | لأي شيء تحتاج إلى شرحه أو الدفاع عنه |

:::note[اللوحة تعرض الحال الآن لا التاريخ]

فهي تعكس العملية الآن. وللاتجاهات والمقارنات وأي سؤال عن فترة ماضية، اذهب إلى التقارير.

:::

## إذا لم تظهر

| العَرَض | السبب |
| --- | --- |
| لا مدخل **Dashboard** | لستَ مخطِّطاً ولا من الإدارة |
| فارغة | لا بيانات تشغيلية بعد للفترة المعروضة |
| الأرقام تبدو خاطئة | افحص تقارير جودة البيانات أولاً — انظر [نظرة عامة على التقارير](./reporting-overview.mdx) |
