## الغرض

هذه هي الخريطة. كل عنصر قائمة موجود في الإصدار الأول مذكور أدناه، مع الدور الذي يراه والفصل الذي يوثّقه.

## كيف نُظِّمت القائمة

<Screenshot

تجمّع SCOP شاشاتها بحسب **ما تفعله**، لا بحسب نوع السجل.

| القسم | يحتوي | من يراه |
| --- | --- | --- |
| **Dashboard** | ملخّص عملية اليوم | المخطِّط والإدارة |
| **My Work** | رحلات السائق ومحطاته وحدها | السائق |
| **Operations** | عمل اليوم — الطلبات والشحنات والجاهزية والتحميل والرحلات والمحطات والاستثناءات | مستخدم SCOP |
| **Planning** | بناء الخطة اليومية وحوكمتها | المخطِّط |
| **Master Data** | الإعدادات التي تعتمد عليها العمليات | مستخدم SCOP |
| **Governance** | القواعد والأسباب والصلاحيات | مستخدم SCOP |
| **Reporting** | كل المقاييس | مستخدم SCOP |
| **Technical** | التشخيص والنطاق | مسؤول النظام |

## Dashboard

| العنصر | ما يعرض | الدور | الفصل |
| --- | --- | --- | --- |
| **Dashboard** | عملية اليوم في لمحة | المخطِّط والإدارة | [لوحة المعلومات](../reporting/the-dashboard.mdx) |

## My Work

تظهر للسائق وحده، وهي القسم الوحيد الذي يراه السائق.

| العنصر | ما يعرض | الفصل |
| --- | --- | --- |
| **My Trips** | رحلات السائق المسجَّل دخوله، كبطاقات | [تسليم السائق](../execution/driver-delivery.mdx) |
| **My Stops** | محطات تلك الرحلات، كبطاقات | [تسليم السائق](../execution/driver-delivery.mdx) |

وكلاهما مُرشَّح على الرحلات **المُطلَقة فما بعد** — فالسائق لا يرى خطة ما زالت محل نقاش.

## Operations

| العنصر | الكائن | الدور | الفصل |
| --- | --- | --- | --- |
| **Demands** | ما يجب أن يتحرك | مستخدم SCOP | [إدارة الطلب](../demand/demand-management.mdx) |
| **Shipments** | الوحدة القابلة للتخطيط | مستخدم SCOP | [إدارة الشحنات](../shipments/shipment-management.mdx) |

| **Trips** | مركبة وسائق وسلسلة محطات | مستخدم SCOP *(مخفية عن السائق)* | [الرحلات](../execution/trips.mdx) |
| **Stops** | الزيارات الفعلية المفردة | مستخدم SCOP *(مخفية عن السائق)* | [المحطات](../execution/stops.mdx) |

| **Exceptions** | المشكلات التشغيلية المُسجَّلة | مستخدم SCOP | [إدارة الاستثناءات](../exceptions/exception-management.mdx) |

:::note[Trips و Stops مخفيتان عن السائقين عمداً]

يصل السائق إلى رحلاته عبر **My Work**، التي تقدّم نموذجاً مبسَّطاً مصمَّماً للهاتف. أما `Operations → Trips` فيقدّم نموذج المُوزِّع الكامل، وهو مخفي عن مجموعة السائق كي لا يُخلط بينهما.

وإخفاء القائمة تسهيل. أما الأمان فهو قاعدة السجلات تحته — راجع [نموذج أمان السائق](../execution/driver-security-model.mdx).

:::

## Technical

لمسؤول النظام وحده. وهذه أدوات تشخيص، لا عمل يومي.

| العنصر | ما هو | الفصل |
| --- | --- | --- |
| **Domain Events** | كل حقيقة سجّلتها SCOP عمّا فعلته أو امتنعت عنه | [الهوية والتتبّع](../concepts/identity-and-traceability.mdx) |
| **Sequence Counters** | العدّادات خلف المعرِّفات التجارية | [مسؤول النظام](../roles/administrator.mdx) |
| **Execution Events** | ما حدث فعلياً أثناء الرحلة | [الهوية والتتبّع](../concepts/identity-and-traceability.mdx) |
| **Capacity Snapshots** | حمولة المركبة عند كل نقطة من كل مسار | [الرحلات](../execution/trips.mdx) |
| **Travel Matrix** | المسافات والمدد المخزَّنة بين العقد | [عقد التخطيط](../configuration/planning-nodes.mdx) |
| **Pilot Scope** | أي أنواع عمليات تتفاعل معها SCOP، ومن متى | [نطاق التجربة](../configuration/pilot-scope.mdx) |
| **Releases** | سجلات الإصدارات لهذا التنصيب | [نطاق التجربة](../configuration/pilot-scope.mdx) |

## إن كانت قائمة تتوقعها غير موجودة

| المفقود | السبب |
| --- | --- |
| **Planning** | لست مخطِّطاً ولا مدير عمليات |
| **Technical** | لست مسؤول نظام |
| **Warehouse Readiness** و**Loading Tasks** | لست مستخدم مستودع |
| **Supplier Commitments** | لست مستخدم مشتريات |
| **Rule Exemptions** و**Objective Profiles** و**Vehicle/Driver Availability** و**Routes** و**Stop Activities** و**Resource Assignments** | لست مخطِّطاً |
| **Approval Authorities** و**Feature Flags** و**Import Locations** و**Onboarding** | لست مسؤول نظام |
| **Trips** و**Stops** | أنت سائق — استخدم **My Work** |
| كل ما تحت `SCOP` | تحمل **Finance User** وحدها، وهي بلا قائمة في الإصدار الأول |
