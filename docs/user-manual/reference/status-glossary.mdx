## How to use this page

You are looking at a record and do not know what its status means. Find the object, find the
label, read the line.

For how the states connect, see [Lifecycle Reference](./lifecycle-reference.mdx).

:::note[Terminal means nothing leaves it]

A **terminal** status is the end of that record's life. Where a requirement still needs
fulfilling, it continues in a **follow-up demand** rather than by reopening the closed one.

:::


## Demand

| Status | Meaning | Terminal |
| --- | --- | --- |
| **Draft** | Just created from the Odoo transfer. Still editable. | No |
| **Submitted** | Put forward as a requirement, awaiting a planner. | No |
| **Validated** | Checked. Ownership is resolved on every line. | No |
| **Eligible for Planning** | Available and ready enough to plan. Its shipment now exists. | No |
| **Planned** | Placed on a daily plan that is not yet released. | No |
| **Released** | On an authorised plan. Committed to today. | No |
| **In Execution** | On a vehicle that has departed. | No |
| **Partially Completed** | Some delivered, some remaining. A follow-up exists. | No |
| **Completed** | Everything requested was delivered. | **Yes** |
| **Failed** | Nothing was delivered. A follow-up exists. | **Yes** |
| **Rejected** | Refused as a requirement, with a reason. | **Yes** |
| **Cancelled** | Withdrawn. | **Yes** |

## Daily Plan

| Status | Meaning | Terminal |
| --- | --- | --- |
| **Generated** | A planning run produced it. Nobody has reviewed it yet. | No |
| **Under Review** | Submitted, awaiting an Operations Manager. | No |
| **Modified** | A planner changed the recommendation, with a recorded reason. | No |
| **Approved** | Authorised and frozen. Records who approved it and when. | No |
| **Rejected** | Refused, with a reason. Can be replanned. | No |
| **Released** | Real work. Trips are visible to drivers and loading tasks exist. | **Yes** |

→ [In full](../planning/the-daily-plan.mdx)

## Planning Run

| Status | Meaning | Terminal |
| --- | --- | --- |
| **Requested** | The run exists; the provider has not been called yet. | No |
| **Evaluating** | The provider is working. The request is recorded. | No |
| **Recommended** | An answer came back and a plan was created. | No |
| **Reviewed** | The resulting plan has entered Under Review. | No |
| **Failed** | The provider raised an error or timed out. Retry is available. | No |
| **Closed** | The resulting plan was released or rejected. | **Yes** |
| **Cancelled** | Withdrawn before an answer. | **Yes** |

→ [In full](../planning/planning-runs.mdx)

## Trip

| Status | Meaning | Terminal |
| --- | --- | --- |
| **Draft** | Created but not yet part of a recommendation. | No |
| **Recommended** | A planning run proposed it. | No |
| **Under Review** | Submitted for authorisation. | No |
| **Modified** | Changed after review began. | No |
| **Approved** | Authorised. | No |
| **Released** | Visible to its driver. Loading tasks exist. | No |
| **Loading** | Loading has started. The vehicle is held at the gate. | No |
| **Ready to Depart** | Loading is finished. The driver may go. | No |
| **In Progress** | The vehicle has departed. | No |
| **Exception** | A problem has interrupted it. | No |
| **Completed** | Every stop completed. | **Yes** |
| **Partially Completed** | Every stop has an outcome; not all completed. | **Yes** |
| **Cancelled** | Withdrawn. | **Yes** |

## Loading Task — Status

Not a governed lifecycle. A plain status field.

| Status | Meaning | Terminal |
| --- | --- | --- |
| **Pending** | Created when the trip was released. Not started. | No |
| **In Progress** | Loading has begun. The trip is held at **Loading**. | No |
| **Done** | Loading is finished. Actual duration recorded. | No |
| **Cancelled** | Not going to happen. | No |

→ [In full](../execution/loading-operations.mdx)

## Warehouse Readiness

Not a lifecycle at all. **Computed from evidence**, and it can move in either direction.

| Readiness | Meaning | Plannable |
| --- | --- | --- |
| **Ready** | Everything is staged. | **Yes** |
| **Conditionally Ready** | Reserved for the whole shipment, not yet staged. | **Yes** |
| **Partially Ready** | Only part can be covered. | No |
| **Not Ready** | Nothing prepared, or the shipment has no lines. | No |
| **Blocked** | Ownership unresolved, or every transfer cancelled. | No |

→ [In full](../readiness/warehouse-readiness.mdx)

## Rule Evaluation — Result

| Result | Meaning |
| --- | --- |
| **Not Applicable** | The rule did not apply to this record. |
| **Passed** | The check succeeded. |
| **Failed — Warning** | Failed, but not blocking. |
| **Failed — Approval Required** | Needs an authorised approval to proceed. |
| **Failed — Blocking** | Refused. |
| **Exception Applied** | An approved exemption was in force. |
| **Unable to Evaluate** | The check could not run; the rule's own setting decided what happened. |
| **Suspended** | The rule was suspended, so the check was not run. |
