**Role**
Everyone.

**Navigate to**
`SCOP`

## Purpose

This is the map. Every menu entry that exists in Release 1 appears below, with the role
that sees it and the chapter that documents it.

## How the menu is organised

SCOP groups its screens by **what you are doing**, not by what kind of record it is.

| Section | Contains | Who sees it |
| --- | --- | --- |
| **Dashboard** | A summary of today's operation | Planner, Management |
| **My Work** | A driver's own trips and stops, and nothing else | Driver |
| **Operations** | The day's work — demands, shipments, readiness, loading, trips, stops, exceptions | SCOP User |
| **Planning** | Building and governing the daily plan | Planner |
| **Master Data** | The configuration operations depends on | SCOP User |
| **Governance** | Rules, reasons, authorities | SCOP User |
| **Reporting** | Every measure | SCOP User |
| **Technical** | Diagnostics and scope | Administrator |

## My Work

Visible only to a Driver, and the only section a Driver sees.

| Entry | What it shows | Chapter |
| --- | --- | --- |
| **My Trips** | The signed-in driver's own trips, as cards | [Driver Delivery](../execution/driver-delivery.mdx) |
| **My Stops** | The stops on those trips, as cards | [Driver Delivery](../execution/driver-delivery.mdx) |

Both are filtered to trips that are **released or later** — a driver does not see a plan
being argued over.

:::note[Trips and Stops are deliberately hidden from Drivers]

A Driver reaches their trips through **My Work**, which serves a simplified form built for
a phone. `Operations → Trips` serves the dispatcher's full form, and is hidden from the
Driver group so the two are never confused.

Hiding the menu is a convenience. The security is the record rule underneath it — see
[Driver Security Model](../execution/driver-security-model.mdx).

:::

## If a menu you expect is missing

| Missing | Reason |
| --- | --- |
| **Planning** | Not a Planner or Operations Manager |
| **Technical** | Not an Administrator |
| **Warehouse Readiness**, **Loading Tasks** | Not a Warehouse user |
| **Supplier Commitments** | Not a Procurement user |
| **Rule Exemptions**, **Objective Profiles**, **Vehicle/Driver Availability**, **Routes**, **Stop Activities**, **Resource Assignments** | Not a Planner |
| **Approval Authorities**, **Feature Flags**, **Import Locations**, **Onboarding** | Not an Administrator |
| **Trips**, **Stops** | You are a Driver — use **My Work** |
| Everything below `SCOP` | You hold only **Finance User**, which has no menu in Release 1 |
