## Purpose

A single screen answering *what is happening right now*, for a planner starting the day or a
manager glancing at the operation.

**Audience**
Planner / Dispatcher and Management. It is not visible to other roles.

**Navigate to**
`SCOP → Dashboard` — the first entry under `SCOP`.

## What it shows
<Screenshot
  src="user-manual/71-dashboard.png"

The dashboard summarises today's operation from the same data the reports read. It is a
**starting point**, not an analysis tool: every figure on it has a report behind it that can
be filtered, grouped and pivoted.

| Reading | Go deeper at |
| --- | --- |
| Demand not yet planned | [Unplanned Demand](./unplanned-demand-report.mdx) |
| Plans awaiting approval | `Planning → Daily Plans` |
| Trips in progress | `Operations → Trips` |
| Open exceptions | [Exception Ageing](./exception-ageing.mdx) |
| Service performance | [OTIF](./otif.mdx) |
| Coverage | [Plan Coverage](./plan-coverage.mdx) |

## When to use it, and when not

| Use the dashboard | Use a report |
| --- | --- |
| Starting your day | Answering a specific question |
| A quick health check | Anything needing a filter or a date range |
| Showing someone the operation | Anything you need to explain or defend |

:::note[The dashboard shows current state, not history]

It reflects the operation now. For trends, comparisons or any question about a past period,
go to the reports.

:::

## If it does not appear

| Symptom | Cause |
| --- | --- |
| No **Dashboard** entry | You are not a Planner or Management |
| It is empty | No operational data yet for the period shown |
| Figures look wrong | Check the data-quality reports first — see [Reporting Overview](./reporting-overview.mdx) |
