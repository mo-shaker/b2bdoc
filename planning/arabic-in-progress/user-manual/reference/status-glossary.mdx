## كيف تستخدم هذه الصفحة

أنت تنظر في سجل ولا تعرف معنى حالته. جِد الكائن، وجِد التسمية، واقرأ السطر.

ولمعرفة كيف تتصل الحالات، انظر [مرجع دورات الحياة](./lifecycle-reference.mdx).

:::note[«نهائية» تعني ألّا شيء يغادرها]

الحالة **النهائية** هي نهاية حياة ذلك السجل. وحيث يبقى متطلبٌ يحتاج وفاءً، يستمر في **طلب متابعة** لا بإعادة فتح المغلق.

:::

## الطلب

| الحالة | المعنى | نهائية |
| --- | --- | --- |
| **Draft** | أُنشئ للتوّ من تحويل Odoo. وما زال قابلاً للتحرير. | لا |
| **Submitted** | طُرح متطلباً، ينتظر مخطِّطاً. | لا |
| **Validated** | فُحِص. والملكية محلولة على كل سطر. | لا |
| **Eligible for Planning** | متاحٌ وجاهزٌ بما يكفي للتخطيط. وشحنته صارت موجودة. | لا |
| **Planned** | وُضِع على خطة يومية لم تُطلَق بعد. | لا |
| **Released** | على خطة مفوَّضة. ملتزَمٌ به اليوم. | لا |
| **In Execution** | على مركبة غادرت. | لا |
| **Partially Completed** | سُلِّم بعضه وبقي بعضه. وتوجد متابعة. | لا |
| **Completed** | سُلِّم كل ما طُلب. | **نعم** |
| **Failed** | لم يُسلَّم شيء. وتوجد متابعة. | **نعم** |
| **Rejected** | رُفض متطلباً، بسبب. | **نعم** |
| **Cancelled** | سُحِب. | **نعم** |

→ [بالكامل](../demand/demand-lifecycle.mdx)

## الخطة اليومية

| الحالة | المعنى | نهائية |
| --- | --- | --- |
| **Generated** | أنتجتها تشغيلة تخطيط. ولم يراجعها أحد بعد. | لا |
| **Under Review** | قُدِّمت، تنتظر مدير عمليات. | لا |
| **Modified** | غيّر مخطِّطٌ التوصية، بسبب مُسجَّل. | لا |
| **Approved** | فُوِّضت وجُمِّدت. وتُسجِّل من اعتمدها ومتى. | لا |
| **Rejected** | رُفضت، بسبب. ويمكن إعادة تخطيطها. | لا |
| **Released** | عملٌ حقيقي. فالرحلات مرئية للسائقين ومهام التحميل موجودة. | **نعم** |

→ [بالكامل](../planning/the-daily-plan.mdx)

| **Closed** | أُطلقت الخطة الناتجة أو رُفضت. | **نعم** |

## مهمة التحميل — الحالة

ليست دورة حياة محكومة. بل حقل حالة عادي.

| الحالة | المعنى | نهائية |
| --- | --- | --- |
| **Pending** | أُنشئت حين أُطلقت الرحلة. ولم تبدأ. | لا |
| **In Progress** | بدأ التحميل. والرحلة محتجَزة عند **Loading**. | لا |
| **Done** | انتهى التحميل. والمدة الفعلية مُسجَّلة. | لا |
| **Cancelled** | لن تحدث. | لا |

→ [بالكامل](../execution/loading-operations.mdx)

## جاهزية المستودع

ليست دورة حياة إطلاقاً. بل **محسوبة من الأدلة**، وتستطيع التحرك في أي اتجاه.

| الجاهزية | المعنى | قابلة للتخطيط |
| --- | --- | --- |
| **Ready** | كل شيء مُجهَّز. | **نعم** |
| **Conditionally Ready** | محجوزٌ للشحنة كلها، ولم يُجهَّز بعد. | **نعم** |
| **Partially Ready** | جزءٌ منها فقط يمكن تغطيته. | لا |
| **Not Ready** | لم يُهيَّأ شيء، أو الشحنة بلا أسطر. | لا |
| **Blocked** | الملكية غير محلولة، أو كل تحويل أُلغي. | لا |

→ [بالكامل](../readiness/warehouse-readiness.mdx)

## تقييم القاعدة — النتيجة

| النتيجة | المعنى |
| --- | --- |
| **Not Applicable** | لم تنطبق القاعدة على هذا السجل. |
| **Passed** | نجح الفحص. |
| **Failed — Warning** | أخفق، ولا يحجب. |
| **Failed — Approval Required** | يحتاج اعتماداً مفوَّضاً للمضيّ. |
| **Failed — Blocking** | مرفوض. |
| **Exception Applied** | كان إعفاءٌ معتمَد سارياً. |
| **Unable to Evaluate** | تعذّر تشغيل الفحص؛ وضبط القاعدة نفسها قرّر ما حدث. |
| **Suspended** | كانت القاعدة موقَفة، فلم يُشغَّل الفحص. |
