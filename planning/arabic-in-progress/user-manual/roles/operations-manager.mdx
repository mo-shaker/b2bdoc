## مسؤوليتك

أنت دور **التصريح**. تقرّر أن يوم التشغيل المقترح مقبول، وتتحمّل تبعة إطلاقه.

وترث كل ما يستطيعه **المخطِّط** و**المستودع**، فتستطيع أداء العمل والتصريح به معاً — بقيد واحد حاسم.

## القيد الوحيد

:::danger[لا تستطيع اعتماد خطة أنشأتها]

يرفض `BR-PLN-001` الاعتماد والإطلاق من مؤلف الخطة، ويعلو على كل صلاحية إدارية في النظام.

فإن بنيت خطة بنفسك، وجب أن يعتمدها **مدير عمليات آخر**.

:::

وهذا سبب عجز فريق من شخص واحد عن إتمام دورة SCOP، وهو مقصود.

**مُتحقَّق منه على `b2b`:** رفض النظام اعتماد **مسؤول النظام** لخطة أنشأها بنفسه، ثم اعتمدها مدير عمليات لم يُنشئها ونجح.

## يومك

| # | المهمة | أين |
| --- | --- | --- |
| 1 | مراجعة الخطط المنتظرة | `Planning → Daily Plans` مُرشَّحة على **Under Review** |
| 2 | قراءة التوصية وأي تعديلات | تبويبا **Recommendation** و**Trips** |
| 3 | مراجعة ما تُرك غير مخطَّط | تبويب **Unplanned Demand** |
| 4 | **Approve** أو **Reject** | ترويسة الخطة |
| 5 | **Release** | الترويسة، بعد الاعتماد |
| 6 | العمل على طابور الاستثناءات | `Operations → Exceptions` |

## الاعتماد

قبل الاعتماد، ثلاثة أمور تستحق القراءة.

| اقرأ | السؤال الذي يجيب عنه |
| --- | --- |
| تبويب **Trips** | هل هناك رحلة غير مجدية من ناحية السعة؟ |
| تبويب **Unplanned Demand** | ما الذي نختار ألّا نفعله اليوم، ولماذا؟ |
| تبويب **Recommendation** | هل غيّر المخطِّط التوصية، وبأي سبب مُعلَن؟ |

و**Approve** يسجّل من اعتمد ومتى. ومن تلك اللحظة تصبح الخطة **مُجمَّدة** — محتواها هو نسخة اليوم المُصرَّح بها.

## الإطلاق

**Release** هو اللحظة التي تصبح فيها الخطة عملاً حقيقياً:

| يفعل الإطلاق | الأثر |
| --- | --- |
| الرحلات ← **Released** | تصبح مرئية لسائقيها |
| الطلبات ← **Released** | يُلتزَم بالمتطلب لليوم |
| إسنادات الموارد ← **committed** | تُحجَز المركبة والسائق |
| إنشاء مهام التحميل | واحدة لكل شحنة على كل رحلة |

:::info[`BR-PLN-002` — الرحلة المحجوبة لا تُطلَق مع خطتها]

إن حملت رحلة على الخطة نتيجة حاجبة — غالباً تجاوز سعة تحت `BR-RTE-001` — رُفض الإطلاق وسُمِّيت الرحلة المخالفة. أصلِح الرحلة أو انزعها من الخطة، ثم أطلِق من جديد.

:::

## الاستثناءات

أنت تملك طابور الاستثناءات. ويُفتح `SCOP → Operations → Exceptions` مُرشَّحاً على المشكلات المفتوحة.

| الخطوة | الزر | ما تحتاجه |
| --- | --- | --- |
| التصنيف | **Classify** | فئة وشدّة |
| الإسناد | **Assign** | مالك. ويُنشئ له نشاطاً |
| التحقيق | **Investigate** | — |
| تحديد المعالجة | **Define Resolution** | إجراء معالجة واحد على الأقل |
| التنفيذ | **Start Resolution** | — |
| التأكيد | **Resolve** | إنجاز كل إجراءات المعالجة |
| الإغلاق | **Close** | — |

والاستثناء الذي يخرق اتفاقية مستوى خدمته **يُصعَّد تلقائياً** ويُخطر المجموعة المسؤولة. وراقب [تقادم الاستثناءات](../reporting/exception-ageing.mdx) لما تجاوز موعده.

:::note[ساعة اتفاقية الخدمة تبدأ عند الاكتشاف]

الفئة إلزامية عند إنشاء الاستثناء، والموعد النهائي يُحسب منها فوراً. فالاستثناء في **Detected** يتقادم بالفعل ويظهر متأخراً متى مرّ موعده — والتصنيف إقرار بأن أحداً نظر فيه.

:::

## قوائمك

كل ما يراه المخطِّط والمستودع، إضافةً إلى صلاحية التصرف في:

| القائمة | استخدامك الخاص |
| --- | --- |
| `Planning → Daily Plans` | الاعتماد والإطلاق والرفض |
| `Operations → Trips` | اعتماد الرحلات المفردة وإطلاقها |
| `Operations → Exceptions` | ملكية الطابور |
| `Reporting → Plan Coverage` | هل خطّطنا ما كان قابلاً للتخطيط؟ |
| `Reporting → OTIF` | هل وفينا بوعودنا؟ |
| `Reporting → Decision Quality` | كم مرة نتجاوز التوصية؟ |
| `Reporting → Exception Ageing` | ما الذي تجاوز موعده؟ |

## ما لا يجوز لك

| غير مسموح | من يقوم به |
| --- | --- |
| اعتماد أو إطلاق **خطتك أنت** | مدير عمليات آخر |
| تغيير نطاق التجربة أو الصلاحيات أو مفاتيح الخصائص | مسؤول النظام |
| حذف سجلات SCOP | مسؤول النظام |
| كتابة كمية مسلَّمة | لا أحد |
| **إنهاء مهمة تحميل** | المستودع — فهي تحتاج **Inventory → User** ولا تملكها |

## إذا كان هناك خلل

| العَرَض | تحقّق من |
| --- | --- |
| **Approve** يُرفض برسالة فصل مهام | أنت أنشأت هذه الخطة. يعتمدها غيرك |
| **Approve** غير معروض | الخطة ليست **Under Review** — لم يرفعها المخطِّط |
| **Release** يُرفض | رحلة تحمل نتيجة حاجبة — `BR-PLN-002` |
| **Done** على مهمة تحميل يرفع خطأ وصول على `Stock Move` | تنقصك **Inventory → User**. هذا عمل المستودع |
| استثناء لا يُعالَج | إجراء معالجة ما زال مفتوحاً |
| تقادم الاستثناءات فارغ | لم تُرفع استثناءات بعد |
